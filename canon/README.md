## 現行基準

- 正式題名：**The Black Wall**
- 外国側呼称：神乃国
- 当事国の自称：不明
- 神記と西暦：`神記N年 = 西暦（N - 1284）年`
- 候補鉱物の計画調査地点：アライ北麓、南方の陸地の2か所
- 1592年アライ調査：鉱床存在可能性を推定。標本未取得
- 1592年南方調査：候補域到達未確認、目的鉱物未発見、標本未取得、19名死亡
- 1597年・1598年の物理的候補現物：セル地区国有銀山の国内第1候補鉱石1点のみ
- 旧稿の「西方3採取区」、採掘量、精錬量、比較試料の値は使用しない
- 1599年8月：核技術研究所研究棟完成
- 1599年11月：国内第1候補鉱石の微量分取を限定許可下で開始
- 1600年1月：原子炉関連原出力と五人の独立変換を交付
- 1600年2月：第一核熱発電所を5項目に限定して着工
- 1601年12月：西方標本供給路の検討開始
- 1602年以降：アライ北麓の地表・古い捨石を対象とする新規調査
- 1604年春：西方第1正式納入荷用の採取開始
- 1604年5月：炉建屋完成。原子炉・燃料・発電所は未完成
- 1604年6月〜7月：国内鉱山地区再調査第1段階。安定供給工程は成立せず停止
- 1604年7月：マーサと惟歳はともに5歳
- 1604年11月：西方第1正式納入荷がペルシャ湾岸港から出航
- 1605年夏：西方第1正式納入荷が本国港へ到着。一部受領、一部条件付き受領、一部受領保留
- 1605年11月：未確認試料特別輸送暫定規程を制定し、第1回国内輸送を完了
- 1606年1月：炉1基、定格熱出力30MW、発電機端6MW、送電端5MWの変換照合完了
- 1606年2月：炉、冷却、発電、非常電源及び工程の人間側初期構成案を作成
- 1606年3月：付属建屋地盤調査、実寸模型、黒鉛量産試験及び圧力管材料試験を開始
- 1606年4月：熱交換設備、タービン・発電機棟、冷却水路及び二つの非常電源区画の配置を確定
- 1606年5月：確定区画から付属建屋基礎工事を開始
- 1606年夏：炉本体、完成燃料、初回臨界及び送電は未実施
- 1607年10月まで：港から研究所までの3回の輸送試行を完了し、未確認試料特別輸送暫定規程を通常規程へ移行
- 1607年10月：官許新聞がレオニス・ヴァレル逮捕、軍務省管理、捜査中、詳細非公表を報道
- 1607年11月：ベガ島東方約200キロメートルで、御前側交付物による核爆発実験を実施。実験船は帰還せず、参加人員は全員帰還
- 1607年11月以後：実験地点周辺を期限未定の立入、漁労及び採水禁止区域とする。「神は生きている」という言葉が広がる
- 1608年7月：人間側が加工した燃料一組で核発電を確認。臨界、停止操作及び残留熱を確認。安全、長期運転、定格及び送電端5MWは未確認
- 1608年7月：御前から「選民地区まで送電線を通せ」と国家命令が示され、経路測量を開始
- 1609年1月：賢人会議の九人が、御前がいなくなる日が近い可能性を共有。一般治安、軍務警備及び近衛警備の三系統分離を再確認
- 1610年11月18日：送電線を黒い壁へ接続。接続用設備面が露出するが通電は行わない
- 1610年12月1日：黒い壁へ送電端5MWを30分通電。接続部周囲に細い光が出現。首都の一部で供給制限
- 1610年12月3日〜6日：御前移動及び市民選別の噂からリデル市総督府襲撃へ発展。総督エルダ家ラウル死亡。軍が鎮圧し、内務卿ミレアは親族として本件調査及び裁定から忌避
- 1611年1月：海外拠点の総督及び官吏の召還、軍務省海外派遣部隊の帰還、国外資産及び記録の回収を決定。御前及び総統から命令を受けられない場合の統治継続制度作成を決定
- 1611年3月：出入国及び外国船入港停止令を発令。施行は6月1日0時。ハイセルの供給契約に基づく事前登録船のみ1航海ごとの例外
- 1611年5月15日：ハイセルが西方鉱石を伴ってリデル市へ入港
- 1611年5月20日：施行前出国申請の受付終了
- 1611年5月24日：黒い壁の接続用設備面が閉鎖。接続金具は床へ落下。閉鎖理由及び御前の状態は未確認
- 1611年5月27日：矢崎惟、矢崎柚、惟歳及びマーサが同じ船で上戸へ向け出国。トゥグルグとセーラは本国に残る
- 1611年5月27日：柚が灰色の帳面原本を国外へ持ち出す。研究所には5月24日までの照合済み写しを残し、セーラが新しい灰色の帳面を開始
- 1611年6月1日0時：出入国及び外国船入港停止令を施行
- 1611年6月2日：黒い壁の接続用設備面が同じ位置へ再出現。紙及び声はなく、技術省は目的不明を理由に再接続を保留
- 1611年6月3日：総統府命令により接続金具及び送電線を再接続。通電なし
- 1611年6月4日：黒い壁への段階的通電を再開し、送電端3MWまで到達
- 1611年6月7日：総統名義の送電端5MW維持指示に対し、トゥグルグが4MW到達前に出力上昇を停止。危険を進言するため選民地区へ入り、御前の命令として処理された発言により拘束
- 1611年6月7日：ゲールが権限外で出力上昇を再開。送電端5MW到達後、セーラが異常の同時進行を確認し、緊急停止及び送電遮断を指示。炉建屋で2回以上の爆発を伴う原子炉重大事故が発生
- 1611年6月7日以後：トゥグルグ及びセーラの生死・所在は未確認。ゲールは事故3日後に重傷状態で発見
- 1611年6月7日：停電、通信途絶及び対象区域を失った複数命令により首都で混乱が発生。橋の軍と近衛、群衆の間で首都暴動開始直前まで進む
- 西方試料の物質名、第92元素含有、国内候補石との同一性、燃料適合性は未確認
- 第21章以降、惟と柚は婚姻済み
- 第21章以降の柚の正式姓名：矢崎柚
- 第20章は婚姻・姓名統合補正の対象外
- 1611年12月2日：破局。6月7日の原子炉重大事故とは別事件
- マーサ死亡：1632年4月、33歳
- アズナル：1613年7月生まれ
- 1634年4月末：アズナルと一房は峯村を離れ、島原で宗門確認及び絵踏を受けた後、諫早方面及び大村湾沿岸を経て平戸へ戻る
- 1634年末頃：アズナルはオランダ東インド会社の航路を利用してインドへ戻る。正確な寄港地及び到着港は未確認
