## 作品概要

戦国時代、日本の南方には、黒い壁の向こうから届く声に導かれ、同時代をはるかに超える文明を築いた国家があった。

外からその国へ入ることを許されるのは、奴隷として買われた少年少女だけだった。

西暦1580年。豊前国宇佐・長洲から連れ出された15歳の少女、市は、海を越えた国で300金貨の奴隷負債を登録される。精密な帳簿、正確な給与、整った法律。しかし、正しく処理された数字の中で、市の手には何も残らない。

本作は、本編を未読の読者にも単独で読めるよう、外伝「市」全4話の確定事実を一つの中編へ再構成した独立版である。

## 読書上の位置づけ

本作は、**The Black Wall本編の第0話ではなく、作品世界へ別の入口から入る独立中編**である。
