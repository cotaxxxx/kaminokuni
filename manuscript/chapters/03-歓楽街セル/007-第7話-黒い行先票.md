# The Black Wall

## 第3章　歓楽街セル

### 第7話　黒い行先票

神記2872年（西暦1588年）春。

出発の日。

リデル第一基礎教育院の正門前には、修了者163人が集められていた。

全員が荷物を1つずつ持ち、首には進路を刻んだ金属札を下げている。

惟の札には、軍務基礎課程。

柚には、商業・接遇課程。

トゥグルグには、大学予備課程。

宗吉には、鉱山課程。

手には、前日の練習で配られた行先票があった。

惟とトゥグルグは白。

柚は青。

宗吉は黒。

職員が列の前を歩いた。

「中央駅までは全員同じ列車です。駅到着後は、行先票の色に従って分かれなさい」

白はバビロン方面。

青はリデル市内。

黒はセル・鉱山地区方面。

「金属札は首から外さないこと。行先票は改札で提出します。他人へ渡さないこと」

何度も聞いた説明だった。

惟は白い票を上着の内側へ入れた。

柚は青い票を、小さな布袋へしまった。

トゥグルグは、票の表と裏を見比べていた。

「何を見ている」

惟が尋ねた。

「紙の作りが違います」

「何と」

「教科書に使われている紙より厚い。水に濡れても、すぐには破れない」

「今日は雨ではない」

「雨が降らないとは限りません」

柚が横から言った。

「トゥグルグは、何でも調べないと気が済まないんだね」

「調べても分からないことはあります」

「それでも調べるの？」

「分からないままにする理由がありません」

柚は惟を見た。

「やっぱり変だね」

「1年間、ずっと言っているな」

「1年たっても変だから」

少し離れた場所で、宗吉が3人を見ていた。

右手は、上着の袖口に触れている。

袖の内側には、細く折った黒い行先票があった。

◇

リデル中央駅は、前日に行った練習よりも混雑していた。

蒸気機関車が煙を吐き、汽笛を鳴らす。

荷車を押す人足。

乗客を呼ぶ駅員。

木箱を運ぶ兵士。

泣いている子ども。

別れを惜しむ家族。

屋根の下に声と煙がたまり、案内の言葉が何度も聞き取りにくくなった。

修了者たちは、引率職員を先頭に改札前の広場へ進んだ。

「ここから色別に分かれます！」

職員が叫んだ。

白。

青。

黒。

練習したとおり、人の流れが3つに分かれた。

白票の列では、乗車口の手前で金属札も確認されている。軍務、大学、行政など、バビロン到着後すぐに別々の施設へ移る者が混じるため、出発前に個人照合を済ませる決まりだった。

黒票の列は違った。

鉱山、工場、鉄道作業所へ向かう者を、教育院が提出した一括名簿で集団移送する。出発時は行先票を回収し、個人の金属札はセルの封鎖された到着区画で照合する。

同じ駅の中でも、確認する場所が違った。

惟は上着から白い行先票を出した。

その時、前を歩いていた者の荷物がほどけた。

衣服と木の器が床へ落ちる。

列が止まった。

後ろから来た者がぶつかる。

惟は柚の肩をかばい、半歩横へよけた。

誰かの肘が、惟の手へ当たった。

白い票が床へ落ちた。

惟が拾おうとした時、後ろから押された。

「進め！」

駅員の声が飛んだ。

宗吉の足が、白い票を踏んだ。

宗吉は身をかがめた。

袖の中から、折った黒い票を落とす。

白い票を拾い上げると同時に、黒い票を指で開いた。

「惟」

宗吉は黒い票を差し出した。

「落とした」

惟は受け取った。

票には1度折られた跡があった。

「これは黒だ」

宗吉は一瞬、息を止めた。

「黒票なら南部線だ」

「私の票は白だった」

「職員が、票の色に従えと言っていた」

宗吉は言った。

考えて作った言葉ではなかった。

口から出たものを、そのまま続けていた。

「札が軍務でも、手にある票に従えって」

「誰が言った」

「向こうの職員だ」

宗吉は、黒い旗の近くにいる男を指した。

帽子と灰色の上着。

荷運びをする人足だった。

煙の中では、駅員と区別がつきにくい。

宗吉は、惟の白い票を袖の奥へ滑り込ませた。

「黒の列が動いている」

惟は黒い票を見る。

印は本物だった。

紙も、教育院で渡されたものと同じだった。

「確認してくる」

惟は人足のところへ向かった。

「黒票は、この列か」

男は惟の手元だけを見た。

「黒なら南部線だ。急げ」

惟が尋ねたのは、自分の進路だった。

男が答えたのは、紙の色だった。

惟は黒い列へ向かった。

宗吉は、その背中を見送った。

袖の中には白い票がある。

これで軍人になれるとは思っていない。

白票の改札を抜ける時には、金属札を確認される。

そこで終わる。

それでも、黒い列車が自分を置いて出ていけばいい。

地下へ向かう列車へ乗らずに済む時間が、ほんの少しでもあればいい。

宗吉は、白い旗へ向かった。

◇

柚は青い列へ並びかけて、足を止めた。

惟が黒い旗の方へ歩いている。

「惟！」

呼びかけても、汽笛に消された。

柚は列を抜けた。

引率職員が止めようとする。

「青はそちらです」

「友達が間違えています」

「自分の列へ戻りなさい」

「すぐ戻ります」

柚は人の間を抜けた。

黒い改札の前で、惟が行先票を渡している。

駅員は票の色を確認し、箱へ入れた。

首の金属札は見なかった。

「惟！」

今度は届いた。

惟が振り返る。

「柚。なぜここにいる」

「それは私の台詞。惟は白でしょう」

「落とした票は黒だった」

「誰が拾ったの」

「宗吉だ」

柚は改札の外を見た。

白い列の中に、大きな背中が見えた。

宗吉の袖口から、白い紙の端が一瞬のぞいた。

「惟、それ――」

発車を知らせる鐘が鳴った。

駅員が柚を押し返そうとする。

「青の者は入れない」

柚は自分の青い行先票を見せた。

「友達を連れ戻します」

「もう発車する」

惟の後ろで、車掌が扉を閉め始めた。

柚は改札の脇をすり抜けた。

「待ちなさい！」

駅員が叫ぶ。

南部線には教育院修了者だけでなく、一般の鉱山労働者、鉄道員、荷役人も乗っていた。車内で教育院の人数を数え直す者はいない。

柚は惟のいる車両へ飛び乗った。

直後に扉が閉じた。

汽笛が鳴った。

床が揺れる。

ホームが動き始めた。

「何をしている」

惟が言った。

「惟を降ろしに来たの」

「もう動いている」

「見れば分かる」

惟は柚を見た。

1年ぶりに聞いた言葉だった。

柚は窓へ駆け寄った。

白い列の前に、宗吉が立っている。

手には白い行先票があった。

白票の改札係が、宗吉の金属札を手に取っている。

鉱山課程。

セル。

札と票が一致しない。

係員が宗吉の腕をつかんだ。

宗吉は抵抗しなかった。

柚と目が合った。

柚は窓をたたいた。

「宗吉！」

列車は速度を上げた。

宗吉の姿が後ろへ流れていく。

白い票は、係員の手へ渡っていた。

「すり替えられた」

柚が言った。

惟は首から下げた金属札を見た。

軍務基礎課程。

だが、列車は南へ向かっている。

「次の駅で降りる」

「停まるの？」

車内にいた労働者が、2人の会話を聞いていた。

「この列車は、セルまで停まらない」

男が言った。

「貨物と労働者をまとめて運ぶ列車だ。途中駅は通過する」

「セルまで、どれくらいですか」

柚が尋ねた。

「半日だ」

窓の外で、リデルの建物が遠ざかっていった。

白い城壁。

港の煙。

1年間暮らした教育院。

それらが、列車の後ろへ消えていく。

トゥグルグは、別のホームからバビロンへ向かう。

宗吉は、白い列の前で拘束された。

柚は青い票を持ったまま、セル行きの列車に乗っている。

惟は黒い票を、すでに改札へ渡してしまった。

「私が確認すべきだった」

惟が言った。

「確認したんでしょう」

「尋ね方を間違えた」

「宗吉が騙したんだよ」

「騙されたのは私だ」

柚は座席へ腰を下ろした。

「私も乗った」

「おまえは降りられた」

「惟を置いて？」

惟は答えなかった。

列車は海岸沿いを南へ進んだ。

◇

セル中央駅で、間違いはすぐに発覚した。

到着者は封鎖された区画へ集められ、金属札を1人ずつ確認された。

惟の札を見た職員が、眉を寄せる。

「軍務基礎課程。なぜ南部列車に乗った」

「黒い行先票を渡されました」

「誰から」

「宗吉という修了者です」

柚も青い票を見せた。

「私は惟を連れ戻そうとして乗りました」

「青票の者が、黒票の改札を通ったのか」

「脇を通りました」

職員は目を閉じた。

怒りを抑えているようだった。

2人は駅の管理室へ連れていかれた。

金属札の番号。

教育院の記録。

中央駅を通過した行先票。

電信でリデルへ照会が送られた。

返事が来たのは、日が沈んでからだった。

宗吉は白票の列で金属札との不一致を発見され、拘束された。

惟と柚の身元も確認された。

だが、2人をすぐに戻す列車はなかった。

リデル方面の旅客列車は10日後。

惟が出頭する予定だった軍務基礎課程では、入所者の受付が当日で締め切られていた。

柚の商業研修先にも、別の者が補充されていた。

セルの内務局員は、電信を机へ置いた。

「次回の配置変更審査は6か月後だ。それまでは、セルから出る許可は下りない」

「6か月？」

柚が聞き返した。

惟は立ち上がった。

「私は軍務基礎課程です」

「記録にはそうある」

「なら、戻してください」

「入所枠は閉じた。次の審査まで待つしかない」

「間違いを起こしたのは、私ではありません」

「改札で票を提出したのは、おまえだ」

役人は惟を見た。

「騙されたことと、確認する相手を誤ったことは別だ」

惟は言葉を失った。

役人は2枚の書類を机へ置いた。

「セル内での仮勤務契約だ。断ることはできる」

柚が書類を見る。

「断ったら？」

「奴隷身分とセルからの移動制限は残る。勤務しない間、通常月額支給はない。国は住居も食事も用意しない」

選べる、と役人は言わなかった。

ただ、断れると説明した。

役人は惟の記録を開いた。

「惟。身体適性、上位。機械理解、良好。北第3鉱区、採鉱補助」

惟の顔が固まった。

「鉱山ですか」

「6か月後に再審査を申請できる」

次に、柚の記録を見る。

「対人理解、言語、接遇に適性あり。温泉歓楽街の接客施設。給仕」

「接客施設？」

「食事と酒を運び、客室を整える。おまえは未成年だ。客を取る仕事は契約に含まれない」

柚は、その言葉の意味を考えた。

「遊郭ですか」

役人は否定しなかった。

「契約内容を読んで、署名するか決めなさい」

惟は書類を読んだ。

柚も読んだ。

断れば、セルには残れる。

だが、眠る場所も食べる物も、自分で用意しなければならない。

2人は署名した。

翌朝、それぞれの勤務先から迎えが来た。

2人は別々の宿舎へ送られた。

セルへ着いて最初の夜、惟と柚は顔を合わせることができなかった。

◇

北第3鉱区の入口は、山の斜面に開いていた。

太い木材で支えられた黒い穴。

穴の前には線路が敷かれ、鉱石を積んだ小さな貨車が並んでいる。

蒸気巻上機。

排水用のポンプ。

換気塔。

火薬庫。

診療所。

設備は、日本の鉱山よりはるかに整っていた。

それでも、穴の中から出てくる男たちの顔は黒かった。

咳をしている者もいた。

惟には、作業着、革靴、手袋、金属製の帽子、灯火が渡された。

監督が言った。

「最初の1か月は採鉱補助だ。支柱材を運ぶ。鉱石を選別する。排水溝を掃除する。勝手に発破場所へ近づくな」

「剣も銃も使わないのですか」

監督は惟を見た。

「ここで銃を撃てば、山が崩れる」

周囲の男たちが笑った。

惟は笑わなかった。

坑道へ入る。

外の光が、背後で小さくなった。

前を歩く者の灯火だけが、岩壁を照らしている。

暗い。

空気が重い。

頭上には、何千、何万という石がある。

宗吉が講堂で言った言葉を、惟は思い出した。

地下は地下です。

宗吉が恐れた場所へ、惟が降りている。

宗吉がこのあとどこへ送られたのか、惟は知らなかった。

恐怖から逃げようとした宗吉は捕まり、その代わりに惟が地下へ入った。

それを不公平だと思うべきなのか。

自分が騙されたことを怒るべきなのか。

考えても、坑道は明るくならない。

惟は父のことも、宗吉のことも、それ以上考えなかった。

考えれば足が止まるような気がした。

「支柱を持て」

命じられた。

惟は木材を肩へ担いだ。

重さで膝が沈む。

「2人で運ぶものだ」

監督が言った。

「1人で持てます」

「持てるかではない。狭い場所で落とせば、後ろの者が死ぬ。2人で運べ」

惟は木材を下ろした。

もう1人の労働者と両端を持つ。

軍務省の役人の言葉を思い出した。

早ければよいとは限らない。

惟は何も言わず、歩調を相手へ合わせた。

◇

柚が送られたのは、セル南側の温泉歓楽街だった。

山から湧く湯が水路を通り、いくつもの浴場へ引かれている。

昼から酒場が開き、夜になると赤い灯が並ぶ。

旅館。

料理屋。

芝居小屋。

賭場。

遊郭。

鉱山労働者、商人、兵士、鉄道員が集まる町だった。

柚の働く店は、3階建ての木造建築だった。

表には大きな提灯が下がっている。

1階は食堂と酒場。

2階と3階に客室。

裏には台所、洗濯場、浴室、従業員の寝室があった。

女将は柚の金属札と契約書を見た。

「15歳。給仕だけ。酒は運ぶ。客室へ1人で入らない」

「分かりました」

「客に名前を聞かれても、本名を教える必要はない」

「どうしてですか」

「名前を知れば、自分のものになったと勘違いする男がいる」

女将は奥へ声をかけた。

「市。新しい子を頼む」

階段から女が下りてきた。

髪を高く結い、薄い紅を引いている。

派手な着物ではなかった。

店の中で働くための、動きやすい衣だった。

「この子？」

「柚。今日から給仕」

市は柚の顔を見た。

次に、手を見た。

「魚を触ってた手だね」

柚は驚いた。

「どうして分かるの」

「爪の形。指の節。それと、魚籠を持つ人は、小指の下が硬くなる」

市は柚の手のひらを返した。

「海辺の生まれ？」

「うん」

「私も」

市は笑った。

「ここでは、私を市姉さんと呼びな」

「お市さん？」

「市でいい。おを付けるほど偉くないよ」

柚は女将を見た。

女将はもう帳面を読んでいた。

市は柚へ前掛けを渡した。

「最初に覚えるのは、客の顔じゃない。逃げ道」

「逃げ道？」

「台所の裏口。2階の外階段。女将を呼ぶ鈴。客が腕をつかんだら、大声を出す前に盆を落とす」

「どうして盆を？」

「音がすれば、店中が見る。男は人に見られると、急に礼儀正しくなる」

市は柚の前掛けを結び直した。

「客に何を言われても、部屋へ1人で行かない。酒を飲まされそうになったら、こぼしたふりをしな。困ったら私の名前を呼ぶ」

「どうして、そこまで教えてくれるの」

市は少しだけ目を細めた。

「15歳の子が、何も知らない顔でここに立ってるから」

「私、顔に出てる？」

「出てる」

柚は市の顔を見た。

「嘘」

市が笑った。

「半分だけね」

その日から、市は柚を妹のように扱った。

客へ料理を出す時は、最初の数日は必ず一緒に入った。

着物の着方。

酒の注ぎ方。

酔った男と、本気で怒っている男の違い。

女将へ言ってよいこと。

言わずに市へ伝えること。

余った料理を、捨てられる前に台所で食べる方法。

市は1つずつ教えた。

夜。

従業員部屋で柚の髪をとかしながら、市が尋ねた。

「リデルに、大切な人でもいた？」

「どうして」

「列車を追いかけて、ここまで来たんでしょう」

「置いていけなかったから」

市は髪をとかす手を止めた。

「そう」

それ以上は言わなかった。

柚は鏡の中の自分を見た。

鏡の端には、市の顔も映っていた。

「市は、どうしてここにいるの」

柚が尋ねた。

「借金」

「いくら」

「人に聞かない方がいいこともある」

「高いね」
