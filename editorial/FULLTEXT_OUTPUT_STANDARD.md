# 『The Black Wall』全文出力規則

**Status: REGISTERED / LOCKED**

この文書は、『The Black Wall』本文を会話上で「全文出す」「全文を出して」等の指示により提示する際の、固定掲載フォーマットを定める。

本文正典そのものを変更する規則ではない。`manuscript/chapters/` の登録済み本文は改変せず、出力時にのみ下記の見出し・文末案内を付加する。

## 1. 正本

話番号、正式話題、章番号、正式章題、五編（I. WIND / II. BLANK / III. EARTH / IV. FIRE / V. WATER）の所属、次話は `manuscript/TOC.md` を唯一の現行正本とする。

## 2. 全文出力時の冒頭形式

各話の全文を提示するとき、冒頭は次の1行見出しとする。

```text
# The Black Wall　　/　{五編名}　/　{章番号}章　{章題}　/　第{話番号}話　{話題}
```

その下から本文を提示する。本文冒頭に登録本文内の話題表示がある場合は、その本文を保持する。

例：

```text
# The Black Wall　　/　IV. FIRE　/　19章　仮設　/　第72話　候補鉱石

第72話　候補鉱石

1598年9月。
```

## 3. 全文出力時の末尾形式

通常回では、本文末尾に次の3項目を付加する。

```text
**NEXT → 第{次話番号}話「{次話題}」**
**目次 → The Black Wall 全話目次**
画像はAI作成です（ChatGPT）
```

NEXTの話番号・話題は `manuscript/TOC.md` に従い、現在話ではなく実際の次話を記載する。

例：第72話「候補鉱石」の場合。

```text
**NEXT → 第73話「進捗」**
**目次 → The Black Wall 全話目次**
画像はAI作成です（ChatGPT）
```

## 4. 付加しないもの

全文出力時には、ユーザーから別途明示指示がない限り、次を付加しない。

- `#長編小説` 等のハッシュタグ
- note画面由来の「スキ」「共有」、著者プロフィール、公開日時、反応数等のUI表示
- 見出し画像URLそのもの
- 本文に存在しない解説、要約、注釈

## 5. 本文保持

本文部分は登録済み原文をそのまま提示する。

- 語句の修正をしない。
- 表記を整えない。
- 改稿しない。
- 要約しない。
- 出力用の冒頭見出しと末尾案内は本文正典とは区別する。

作者から明示的な変更指示が出た場合のみ、この全文出力規則を更新する。
